# ChemLab — Interactive Chemistry Learning Platform

A colourful, modern, fully client-side chemistry e-learning platform.

## Features
- Interactive Periodic Table with search, filters and detailed element cards
- Reaction Simulator with equation, real-world and visual modes
- Handy calculators (molarity, stoichiometry, dilution, temperature)
- Searchable glossary
- Lesson module structure
- Dark / Light mode
- XP system (localStorage)

## Live Demo
Deployed on Vercel.

## Tech
Pure HTML + CSS + Vanilla JS (no build step required).
