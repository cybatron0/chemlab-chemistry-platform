About ChemLab

This is an expanded, fully operational virtual chemistry laboratory.

Data Sources (Free & Open)

  • PubChem (NCBI) — Live compound data via PUG-REST API (100M+ substances).
  • Local Reaction Engine — Curated common reactions spanning acid-base, redox, precipitation, synthesis, decomposition, combustion and selected organic reactions. Expandable.
  • Open Reaction Database (ORD) — Recommended for large-scale organic reaction data: open-reaction-database.org
  • Dot-and-cross diagrams generated programmatically from valence electron rules.

Capabilities

  • Real-time compound lookup (formula, weight, SMILES, IUPAC…)
  • Searchable reaction database with type filters
  • Interactive Lewis / dot-and-cross diagram generation
  • Reactant mixer that matches against known equations

Internet required for PubChem queries. Diagrams and local reactions work offline.
